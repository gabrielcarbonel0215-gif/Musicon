# Proyecto de Música - Canciones y Logos

Este directorio contiene todos los archivos descargados y procesados para el proyecto.

## Estructura de Carpetas

- **`canciones/`**: Los 24 archivos de audio descargados y convertidos en formato **`.m4a`** con la mejor calidad disponible.
- **`logos/`**: Las 24 portadas oficiales de álbumes/singles en alta resolución (1000x1000 píxeles) obtenidas de plataformas de streaming (Apple Music, Spotify, Deezer).
- **`logos_recortados/`**: Las 24 imágenes recortadas directamente de las tarjetas de tu captura de pantalla original.
